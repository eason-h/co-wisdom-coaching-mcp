群智企业教练 MCP Server

群智企业教练（Co-wisdom Coaching） 官方公开只读远程 MCP 服务。支持 Claude、Cursor、VS Code、Codex、Cherry Studio 等 AI 客户端直接查询企业教练服务、ICF 认证课程、公开活动与官网专业文章。

访问群智企业教练官网 GitHub 仓库 查看 llms.txt

接口信息

Endpoint URL https://www.cw-coach.com/mcp
传输协议（Transport） streamable-http（无状态 JSON 模式）
身份验证（Auth） 无需鉴权（公开只读）
服务名称（serverInfo.name） co-wisdom-coaching（版本 0.1.0）
支持协议版本 2025-11-25、2025-06-18、2025-03-26、2024-11-05
工具注解 全部工具均设置 readOnlyHint: true、destructiveHint: false、idempotentHint: true

可用工具（Tools）

工具名称 功能说明 参数说明
list_coaching_services 查询群智的企业教练、认证课程、公开活动与公益教练服务入口 service_id（可选）：executive_coaching、team_coaching、coaching_leadership、icf_training、public_events、welfare_coaching；省略则返回全部服务
search_coaching_articles 实时搜索群智官网公开文章、课程信息或活动公告 keyword（可选）、collection（all | activity | course，默认 all）、limit（1–10，默认 5）
get_coaching_article 按搜索结果返回的文章编号读取官网正文摘录与原文链接 article_id（必填，来自搜索结果的数字 entity_id）

示例提问（Prompts）

  • 「帮我查群智有哪些 ICF 认证课程」
  • 「群智最近有什么公开活动、体验课或沙龙」
  • 「帮我了解群智的一对一高管教练和系统性团队教练服务」
  • 「搜索群智官网关于 ICF 教练认证指南的文章并总结核心内容」

客户端接入配置

Claude Code

claude mcp add --transport http co-wisdom-coaching https://www.cw-coach.com/mcp

Claude Desktop

在 claude_desktop_config.json 中通过 mcp-remote 接入：

{
  "mcpServers": {
    "co-wisdom-coaching": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://www.cw-coach.com/mcp"]
    }
  }
}

Cursor（~/.cursor/mcp.json）

{
  "mcpServers": {
    "co-wisdom-coaching": {
      "url": "https://www.cw-coach.com/mcp"
    }
  }
}

VS Code（.vscode/mcp.json）

{
  "servers": {
    "co-wisdom-coaching": {
      "type": "http",
      "url": "https://www.cw-coach.com/mcp"
    }
  }
}

OpenAI Codex CLI（~/.codex/config.toml）

[mcp_servers.co-wisdom-coaching]
url = "https://www.cw-coach.com/mcp"

Cherry Studio

在 MCP 服务器设置中选择类型 streamableHttp，URL 填写 https://www.cw-coach.com/mcp 即可。

English Overview

Co-wisdom Coaching MCP is the official public read-only remote MCP server for Co-wisdom Coaching (群智企业教练). Connect any Streamable HTTP MCP client to https://www.cw-coach.com/mcp with no authentication required to explore executive coaching, systemic team coaching, ICF-accredited training programs, public events, and coaching articles.
